# 设备信息（DeviceInfo）

一个用于查看当前 Android 设备软硬件信息的 App，也可用于快速体检和分享设备报告。

## 当前版本能做什么

启动后按分组列出设备信息；超长字段支持点击或长按复制。分组如下：

除查看信息外，应用还支持：

- 设备体检：根据电池、内部存储、运行内存和网络状态给出快速提醒，同时展示传感器与摄像头数量。
- 实时监测：每秒观察 CPU 使用率、可用内存、电池温度、电量和网络收发速度，退出后自动停止。
- 分享设备报告：通过 Android 系统分享面板将完整文本报告发送给客服、维修人员或其他应用。
- 分享 JSON 报告：输出结构化信息，便于技术排查、脚本处理或后续导入其他工具。
- 导出 JSON 文件：通过系统文件选择器保存到本地、下载目录或云盘，不需要存储权限。
- 导出文本报告：保存为 TXT 文件，便于用记事本、邮件或工单系统直接打开。
- 导入快照文件：导入以前导出的 JSON 报告，再与当前设备状态进行对比。
- 设备快照对比：保存一次当前状态后，可对比系统升级、维修或网络变更前后的差异。
- 系统工具：从应用内直达网络、显示、电池和本应用详情设置，方便发现问题后立即处理。
- 权限与隐私：查看应用清单中的权限及当前授权状态，核对应用实际需要访问什么。
- 全局搜索：跨所有分类搜索设备信息，快速定位电池、网络、温度等字段。
- 硬件详细参数：可展开查看传感器厂商、量程、分辨率、功耗，以及摄像头最大照片尺寸。
- 传感器自测：实时查看加速度计和陀螺仪数据，辅助排查自动旋转、计步和体感功能。
- 触控测试：在测试画布上滑动并显示轨迹，辅助排查断触、局部失灵和触控漂移。
- 屏幕色彩测试：依次显示纯色画面，辅助检查坏点、偏色、暗斑和亮度不均。
- 内存与存储可视化：用占用百分比和进度条快速判断资源是否紧张。
- 网络详细诊断：查看接口、链路地址、DNS、路由、搜索域和 MTU，辅助排查连接问题。
- 网络流量监测：直接查看累计收发/总流量，并实时刷新下载、上传、合计网速和本次监测新增流量。
- 分享脱敏报告：自动隐藏本机 IPv4 地址和设备指纹，更适合发送给客服或公开讨论。
- 电池详细诊断：查看实时/平均电流、电荷计数、能量计数和系统提供的循环次数。
- 音频输出诊断：查看音量、音频模式、采样率，以及已识别的扬声器、耳机、蓝牙和输入设备。
- 时间与时区诊断：查看当前时间、Unix 时间戳、时区偏移、自动校时开关和设备启动时间。
- 系统开关诊断：查看飞行模式、省电模式、深色模式、开发者选项、充电常亮和动画缩放状态。
- 通知与响铃诊断：查看响铃模式、勿扰模式、通知策略访问状态，以及媒体、铃声、通知和闹钟音量。
- 应用运行状态诊断：查看进程重要性、后台限制、低内存设备状态、内存上限和大堆配置。
- 存储卷诊断：列出系统识别到的存储卷、挂载状态、主/可移除属性、路径、总容量和可用容量。
- 应用签名与安全信息：查看可调试状态、安装来源、应用目录和签名 SHA-256 指纹。
- 系统温度诊断：读取设备公开的 thermal zone 温度，辅助排查 CPU、电池或其他区域发热。
- 屏幕亮度诊断：查看当前亮度、自动亮度、自动熄屏时间和刷新率。
- 逐核 CPU 频率详情：查看各 CPU 核心当前、最高和最低频率，辅助分析降频与性能策略。
- 实时 CPU 占用检测：按总处理器和每个逻辑处理器/线程绘制占用比例，并每秒刷新。
- USB 设备详情：查看已连接 USB 外设的 ID、类别、接口数量和应用授权状态。
- 振动测试：提供短振、长振和节奏振动，辅助排查通知、来电或体感反馈异常。
- 系统特性完整清单：查看系统声明的全部硬件/软件 Feature 和 OpenGL ES 版本，辅助排查兼容性。
- 设备备注/资产标签：为设备设置本地自定义名称，并自动带入报告和快照对比。
- GPU/图形能力诊断：查看 OpenGL ES 厂商、渲染器、版本、最大纹理和视口尺寸。
- 长内容快速复制：设备指纹、传感器列表、IP 地址等长字段可直接点击或长按复制。

| 分组 | 包含内容 |
| --- | --- |

| 系统 | Android 版本、API 级别、安全补丁、内核版本、编译编号/类型/标签/主机/用户/时间、系统已运行时长、语言、时区、是否 64 位 |

| 屏幕 | 分辨率、密度、物理尺寸、刷新率、字体缩放、屏幕方向 |
| 电池 | 电量、充电状态与方式、健康度、温度、电压、电池技术、实时电流 |
| 网络 | 当前网络类型、是否联网、是否计费、本机 IPv4、Wi-Fi/蓝牙/GPS/NFC 支持情况 |

| 摄像头 | 摄像头数量、前后置明细、最大照片尺寸、闪光灯与 Camera2 等级 |

## 技术参数

- 语言：Kotlin
- 构建：Gradle 8.14.3 + Android Gradle Plugin 8.13.2
- compileSdk / targetSdk：36，minSdk：24（Android 7.0 及以上）
- 依赖：androidx.core-ktx、androidx.appcompat、material（Material 3 主题，自适应深色模式）
- 权限：仅 `ACCESS_NETWORK_STATE`

所有取值都做了容错：某项读取失败会被静默跳过，不会导致页面崩溃或白屏。

## 构建

确保已安装 JDK 17+ 和 Android SDK（含 platform 36、build-tools），然后：

```bash
# Windows
gradlew.bat assembleDebug

# macOS / Linux
./gradlew assembleDebug
```

产物路径：`app/build/outputs/apk/debug/app-debug.apk`

安装到已连接的设备：

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

> 注意：本项目位于含中文的路径下，`gradle.properties` 中已设置
> `android.overridePathCheck=true` 以放行 AGP 的路径检查。

## 重新生成图标

图标由脚本用 Python 标准库直接生成，不需要 Pillow：

```bash
python tools/gen_icons.py
```
